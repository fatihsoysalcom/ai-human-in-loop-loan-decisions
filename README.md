# AI Human in Loop Loan Decisions

This example demonstrates a 'Human-in-the-Loop' (HitL) pattern for high-risk AI decisions. It simulates a loan application system where an AI provides a default probability for applicants. Based on predefined risk thresholds, some applications are auto-approved or auto-rejected, while medium-risk cases are flagged for human review and final decision, illustrating human oversight in critical AI processes.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Interact with the prompts for human review cases.
